# 界面截图

本目录用于存放 README 中展示的系统截图。

## 需要放置的文件

按下面的文件名放进来，README 里的图片就会自动显示（**无需修改 README**）。

| 文件名 | 截什么页面 | 怎么截 |
|---|---|---|
| `dashboard.png` | 数据统计首页 | 登录后默认页，等 ECharts 图表加载完再截 |
| `login.png` | 登录页 | 打开 http://localhost:3000 直接截 |
| `messages.png` | 消息记录 | 最好有数据，能看出实时推送效果 |
| `reply-rules.png` | 自动回复规则 | 新建几条规则后再截，能看到 7 种匹配模式 |

## 截图建议

1. **窗口宽度**：建议 1440px 左右（浏览器 F12 → 设备工具栏可精确设置）
2. **只截内容区**：不需要包含浏览器地址栏和书签栏
3. **格式**：PNG（界面截图比 JPEG 清晰，且体积可控）
4. **体积**：单张控制在 500 KB 以内，太大可以压一下
5. **数据**：尽量先造一些演示数据，空表格的截图说服力弱

## 怎么截

Windows 自带工具即可：

- **Win + Shift + S** —— 框选截图（推荐）
- **Win + PrtSc** —— 全屏截图

截完后把文件重命名成上表对应的名字，放进本目录。

## 如果暂时没有截图

README 中对应的图片区块**先注释掉了**，不会显示破图。

等你截好图放进本目录后，把 README 里那段 HTML 注释的 `<!--` 和 `-->` 删掉即可显示。

## 启动系统以便截图

```bash
cd deploy
docker-compose up -d
# 等待约 1 分钟，然后访问 http://localhost:3000
# 账号 admin / 密码 admin123456
```
